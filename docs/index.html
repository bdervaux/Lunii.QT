Gratuit, sans compte et sans publicité. Version 3.1.4.

Pour votre ordinateur

Pour Mac

macOS 11 ou plus récent · Apple Silicon et Intel · 1,2 Mo

Télécharger pour Mac
  1. Ouvrez le zip téléchargé.
  2. Double-cliquez sur « Installer MyLunii.command ».
  3. La première fois, comptez 2 à 5 minutes avec Internet : Python est installé s'il manque.

macOS refuse ? Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ». Ou dans le Terminal : tapez bash, une espace, glissez « installer-mylunii.sh », puis Entrée.

Pour votre ordinateur

Pour Windows

Windows 10 et 11 · tout est inclus, rien d'autre à installer · 74 Mo

Télécharger pour Windows
  1. Clic droit sur le zip › « Extraire tout… ».
  2. Double-cliquez sur « Installer MyLunii.bat ».
  3. MyLunii s'ouvre et apparaît sur le Bureau et dans le menu Démarrer.

« Windows a protégé votre ordinateur » ? Cliquez « Informations complémentaires », puis « Exécuter quand même ».

Plusieurs ordinateurs à la maison ? Un seul zip avec les versions Mac et Windows (78 Mo).
